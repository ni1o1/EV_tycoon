FIELD GUIDE

让每一度电，创造价值。

  1. 先看目标，再开始。 选择关卡后默认暂停，点击 1×、4× 或 8× 营业，空格键可暂停。
  2. 经营现金，不只看收入。 电费实时扣除，维护和贷款每天扣除，租金每期支付。建议准备金覆盖本期租金与三天日常支出。
  3. 价格与客流要平衡。 售价越高，客户越少。已进站车辆按进站价格收费，调整价格影响后续客户。
  4. 能源自动调度。 光伏优先，谷价（≤ $0.45）储能充电，高价放电。配电不足会限速，离网时只使用光伏与电池。
  5. 关卡逐步解锁。 在期限结束时达到经营目标即可通关。更好的资金结余能获得更多星级。
  6. 自动保存，随时回来。 同一浏览器可继续上次经营，打开银行、指南或切到后台都会暂停。模拟贷款日利率为 2%。
