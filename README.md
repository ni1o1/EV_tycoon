# EV 大亨 · 一度电，一座城

[在线游玩](https://ni1o1.github.io/EV_tycoon/) · 原生 JavaScript / Canvas 充电站经营模拟游戏。

## v3.0 · 从单桩教学到长线成长战役

- 顶栏是品牌加四个按钮：`关卡`、`目标`、`成就` 与一个不写文字的速度按钮（没有正在经营的局时「目标」为不可点状态）。速度按钮每次点按在 1× → 4× → 8× → 暂停 → 1× 之间循环，图标依次是单三角、双三角、三三角与暂停方块；原先的副标题、问号与整行速度控制条都已去掉，玩法指南移到选关页。
- 主屏明确显示当前电网单价（$/kWh）与最近十分钟的资金变化；储能从电网充电也会计入电费，光伏供电与离网时不产生购电费。资金卡为白底账本样式，金额统一按同一套配色：**加钱绿、扣钱红**，资金变化、昨日净收支、今日变化、记账盈亏、维护与租金、账单与飘字同样适用；「资金不足」「配电过载」这类警示文字仍用红色。
- 手机主屏固定为一个视口，顶部只有两张卡片：资金，以及合并了时间与天气的一张卡。资金卡首行是「资金 + 银行」，右侧并排昨日与今日的变化；主数字旁边是最近十分钟的资金变化；下面一行写清维护、租金（含倒计时）与还款。时间天气卡上排是 D15 与 08:10 的精确读数，下排是天气图标与名称、光伏效率与明日预报——太阳位置只在场景天空里表现，顶栏不再单独画日弧。其下依次是站点场景、能源曲线，以及最底部的电价与设备操作（390×844 下顶栏 74px、底行 106px，场景 411px、曲线 180px）。原来的关卡进度整行已删除，场景框里也不再压任何入口——关卡目标与技术成就都移到顶栏，画面只留右上角的充电占用率。
- 天气画进站点场景顶部约三成半高度：天空按时刻插值变色，太阳与月亮用和时钟同一套位置公式移动并**在两回合之间连续插值**（不会一顿一顿），太阳周围的光芒缓慢旋转，云层按风向持续飘过（晴天也有云），暴雨会闪电，晴朗夜里有星空，阴雨天整体压暗。雨效分三层景深：远近不同的雨丝按各自速度连续下落并带上风向斜度，地面同时泛起一圈圈扩散的落地水花。
- 能源曲线只画已经拥有的项目：没有光伏或储能时，图例与曲线都不出现，买入第一组后才加入；供电条与运营条已并入资金卡和能源面板，省下的高度留给场景。售价滚轮、成本电价与每度毛利集中在最下方左侧一列（竖排，宽度只占 94px），右侧是可购买的设备；六台设备按 3×2 撑满自己那一格，格位与按钮之间不留空档，底行比原来矮了 50px。
- 售价用一个小滚轮，观感对齐 iOS 选择器：整列 26 个取值纵向排开、同时露出 5 行（行高由 `--row` 控制，随屏幕高度取 13/11/10 px），中间一格加粗放大并压在带细线的白色选择带上，越靠边越淡越小，窗口上下还有一层渐隐；上下拖动可以连续滚动（松手按速度多滑一点再吸附到整格）、点某一格直接选中、滚轮与上下键按 $0.1 微调；拖动过程中价格实时更新，松手才写存档。减少动态效果时不做过渡动画。成本电价（电网分时电价）显示在滚轮下方，再下一行是**每度毛利**（售价减成本电价，绿字；售价低于成本时红字），所以车旁跳出的金额可以直接对上：金额＝送出的度数 × 每度毛利。
- 原来的「经营」按钮已删除，其中的累计交付、建议准备金、可投资金额、历史账本与银行入口都收进「关卡目标」面板里可按需展开的一段。
- 24 小时能源曲线始终显示在主屏：昨日电网、光伏供车、储能供车、电网进口及新增充电负荷（尚未拥有的项目不显示）；点按可查看时刻功率（kW）。曲线来自实际十分钟调度，不用平滑曲线改变峰值。
- 站点采用手绘矢量场景，车辆有车窗、车轮、车灯和车身立体面，充电桩有屏幕、枪与线缆；车辆停进车位后会从充电枪拉一条线接到车身充电口，光伏屋顶、储能柜、配电柜（每买一组 +20kW 就在场地多摆一台，最多画三台再标数量）与充电进度都对应实际设备状态。实际客户从道路驶入，充满或超时后驶出；动画随暂停冻结、支持减少动态效果，渲染与收费相互独立。
- 车辆电量进度条按电量从红到黄再到绿：刚进站的低电量车是红的，过半转黄，接近满电变绿，百分比数字同色。
- 每十分钟结算一次，就在正在充电的车**四周**同时冒出四处纯文字（无底色，带白色描边保证可读），先快速放大再慢慢褪去上浮：第一行是这辆车这一回合到账的金额（`+$0.99`），第二行小字写清它是怎么来的（`1.17度 × $0.85`，送出的度数乘以每度毛利），亏本时整条变红并显示负号；每辆车算自己的进账，金额相同也会按回合重跳，资金卡主数字旁的十分钟读数照旧。
- 8 类模拟车辆有不同容量与交流/直流充电上限；到站 SOC 使用截断正态分布 N(20%, 7%²)，限制 5%～50%。车旁显示容量、SOC、实际功率/车辆上限；计费只包含到站后新增的电量。
- 十个模式预设在一屏选关页直接展示，包含各关模式与经营时长；目标说明、准备金和历史账本按需点开，玩法指南分三页，减少常驻信息。
- 解锁跟着关卡走：打赢第 1 关解锁快充，第 2 关解锁光伏，第 3 关解锁储能，第 4 关解锁银行，之后六关不再解锁新设备而是换设定。解锁跨关永久保留；已经解锁过的账号回头再打第 1 关可以直接用快充。新解锁时弹出居中提示卡，写明新设备的价格与作用以及购买入口，可点按关闭或 6 秒后自动消失；同时解锁多项时逐条排队，结算窗口打开时先让位、关闭后再出现。
- 十个关卡**统一以「活过 100 天」为标准**，差别在设定：前四关逐件解锁设备，后六关分别考低客流、离网、雨季、高租金、通胀与高频交租。通关后可继续经营当前站，或以新预设进入下一关；设备解锁保留。
- 选关页只区分两种状态：**已解锁的关卡统一一套蓝色**（通关的加深一档，右上角用 ★ 表示星级），**未解锁的统一灰色**、文字与标签一并淡出，不再按关卡换配色。
- 自动保存当前经营局，刷新后可恢复；保留已解锁关卡。存档仅保存在当前浏览器，开始新局替换当前存档。
- 默认以 1× 自动开始营业；支持 1× / 4× / 8×，空格暂停，切到后台自动暂停。速度、经营与关卡位于游戏主屏顶部；贷款、账单、事件窗口打开时暂停。
- 按实际交付电量收费，最后一次充电不会少收或重复计费。离网模式禁止购电、缺电限速，储能遵守容量与充放电功率限制。
- 贷款采用模拟日利率 2%，预览与实际还款使用同一算法。每日收支包含维护、贷款还款及当日支付的租金，不包含设备投资、贷款入账和随机事件。
- 运行时依赖本地提供，不需要 Tailwind CDN 或 ECharts CDN。手机布局始终显示定价、已解锁设备购买与速度控制；支持键盘与减少动态效果偏好。

## 成长与解锁

开局一台慢充桩、20 kW 基础配电，只能买慢充与配电。设备解锁不再看营业成就，而是**跟着关卡走**：通关即解锁，跨关永久保留，存档只记在账号里。已有设备即使其采购尚未开放也能正常工作；模式限制优先——超充不能买慢充，离网不能买配电。

| 开放项目 | 解锁条件 | 效果 |
| --- | --- | --- |
| 快充 | 通关第 1 关《街角开业》 | 30 kW 直流桩，$2,400，日维护 $35 |
| 光伏 | 通关第 2 关《阳光合伙》 | 白天的免费电源，$1,200/组 |
| 储能 | 通关第 3 关《超充时代》 | 谷电存起来、峰时放出来，$1,800/组 |
| 银行 | 通关第 4 关《峰谷博弈》 | 分期或一次性贷款，日还款计入日结算 |

顶栏的「成就」按钮打开「技术与成就」面板查看全部四项，鼠标悬停会提示下一件解锁的条件（例如「下一件解锁：光伏 · 通关第 2 关《阳光合伙》」）。尚未解锁的设备与银行不出现在主界面。原来的营业成就补贴已随新解锁方式一并去掉，难度相应提高。

十关都是 100 天：活到第 100 天、期间资金不为负、所有到期租金都付清才算通关（一星）。两星与三星看**净资金**——账户余额减未还贷款本金，所以不能靠临近结束借款凑数，门槛写在关卡目标里。每关有各自的初始设备、客流、城市、电价与租金曲线：租金每周（高频租金关每 3 天）递增，越拖越贵；客流是随地点与时段变化的到站期望，没有每日上限，能否接住只看空闲桩位与配电。教学关免随机事件，其余关卡保留天气与事件的不确定性。

按 144 个十分钟回合/游戏日估计，100 天在 1× 下约 120 分钟、8× 下约 15 分钟。实际时长会受到开始时间、暂停和账单/事件操作影响。通关后「继续经营这座站」保留现金、设备和顾客，仍可继续解锁；「下一关」使用独立预设并保留技术成果。

各模式独立机制保留：鬼城客流减半（按到站期望减半）；限电配电每次仅 +10 kW；离网禁止购电、采购优惠 25%，初始存电 150 kWh；雨季持续降雨；豪华客流翻倍且售价接受度更高；通胀同类设备每次涨价 50%；高频租金每 3 天结算。战役使用各关预设租金，通胀关为每周线性递增 $160；自由经营的通胀租金仍保留原指数增长。

设备基础采购价/日维护：慢充 $800/$12，快充 $2,400/$35，光伏 $1,200/$8，储能 $1,800/$18，配电 $1,000/$15；普通模式同类连续采购递增 10%，事件折扣仍生效。

`npm run balance -- 12` 用真实客流、车型、天气、事件、调度与结算规则回放，比较挂机与规划投资；每关按该关开始时账号真实拥有的设备来初始化。固定种子（171 的整数倍）中，**挂机在十关全败**（前半段还能靠初始桩勉强持平，租金涨到中后期就破产），**参考扩建策略在十关全胜**。参考策略不是最优解，结果只代表这些场景，不代表玩家总体通关率；逐步采购计划见 `scripts/balance.cjs`。

旧版星级记录以「旧★」展示，新战役单独评星；旧关卡解锁映射到相应模式和后续关卡，旧记录不删除。正在经营的 v2 存档恢复为经典关卡，保留原期限、租金和目标；继续营业保持当前站点，重试或进入下一关使用对应的新预设。自由经营仍可恢复旧局。

自由经营保留标准、超充、离网、鬼城、豪华、限电、通胀、雨季、高频租金九种模式，目标生存 100 天。城市分时电价为游戏参数，并非实时商业电价。

## 车辆模型

以下是用于探索调度逻辑的虚构车型参数，不对应某个品牌或具体型号。充电至 100%；当前模型使用恒定的接受功率上限，尚未模拟接近满电时的充电降功率。实际功率受车辆交流/直流上限、桩功率、站点配电及可用能源共同约束。标准快充桩额定 30 kW，因此即使车辆支持 150 kW，也只会接受不超过桩与站点允许的功率。

| 车型 | 容量 kWh | AC 上限 kW | DC 上限 kW |
| --- | ---: | ---: | ---: |
| 紧凑车 | 42 | 3.6 | 25 |
| 出租车 | 58 | 7 | 60 |
| SUV | 82 | 11 | 120 |
| 跑车 | 70 | 11 | 150 |
| 巡逻车 | 62 | 11 | 90 |
| 救护车 | 86 | 22 | 100 |
| 厢式车 | 76 | 7 | 50 |
| 皮卡 | 110 | 11 | 180 |

原有存档中已到站、尚无车型参数的车辆保留原来的待充电量和功率规则，驶离后新客户使用新的车型模型。曲线与存档继续兼容 v2。

## 本地运行

```bash
python3 -m http.server 4175 --directory docs
```

打开 `http://localhost:4175/`。运行游戏不需要安装 Node 依赖。

修改样式或运行检查：

```bash
npm ci
npm run build
npm test
npx playwright install chromium
npm run test:layout
npm run balance
```

`npm run build` 将 Tailwind 工具类编译到 `docs/utilities.css`，产物需一并提交。主要自定义样式在 `docs/style.css`。

## 文件结构

- `docs/index.html`：正式入口与语义化界面。
- `docs/campaign.js`：关卡、经营提示、自动存档和增强交互。
- `docs/game.js`：时间循环、设备、客流、事件、结算、站点绘制。
- `docs/vehicles.js`：车型容量、接受功率、初始电量分布与 SOC。
- `docs/station-art.js`：车辆、充电桩与站点矢量美术，独立于调度逻辑。
- `docs/energy.js`：供电调度与实际电量计费。
- `docs/finance.js`：贷款预览、还款和最终本金结清。
- `docs/vendor/`：本地 ECharts 及其许可证。
- `scripts/balance.cjs`：用真实游戏规则进行可复现的数值回放。
- `tests/`：能源守恒、离网、贷款、暂停、存档、目标和完整通关回归测试。
- `docs/index_test.html`：旧测试地址，自动跳转正式版。
