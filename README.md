# EV 大亨 · 一度电，一座城

[在线游玩](https://ni1o1.github.io/EV_tycoon/) · 原生 JavaScript / Canvas 充电站经营模拟游戏。

## v2.3 · 单屏能源经营与数值挑战

- 主屏明确显示当前电网单价（$/kWh）、最近十分钟售电收入（+$）与实际购电费（−$）；储能从电网充电也会计入电费，光伏供电与离网时不产生购电费。
- 手机主屏固定为一个视口，保留原版的资金与实时增减、昨日净收支、天气效率与预报、客流、日维护、每日还款、租金倒计时、事件状态、实时功率、储能状态、电价与设备操作。
- 24 小时能源曲线始终显示在主屏：昨日电网、光伏供车、储能供车、电网进口及新增充电负荷；点按可查看时刻功率（kW）。曲线来自实际十分钟调度，不用平滑曲线改变峰值。
- 站点采用手绘矢量场景，车辆有车窗、车轮、车灯和车身立体面，充电桩有屏幕、枪与线缆；光伏屋顶、储能柜和车辆充电进度对应实际设备状态。实际客户从道路驶入，充满或超时后驶出；动画随暂停冻结、支持减少动态效果，渲染与收费相互独立。
- 8 类模拟车辆有不同容量与交流/直流充电上限；到站 SOC 使用截断正态分布 N(20%, 7%²)，限制 5%～50%。车旁显示容量、SOC、实际功率/车辆上限；计费只包含到站后新增的电量。
- 六关选择也放在一屏；目标说明、准备金和历史账本按需点开，玩法指南分三页，减少常驻信息。
- 六个渐进关卡，明确的经营目标、解锁路线与星级成绩；保留三座城市和九种自由经营模式。
- 自动保存当前经营局，刷新后可恢复；保留已解锁关卡。存档仅保存在当前浏览器，开始新局替换当前存档。
- 默认暂停，手动开始；支持 1× / 4× / 8×，空格暂停，切到后台自动暂停。贷款、账单、事件窗口打开时暂停。
- 按实际交付电量收费，最后一次充电不会少收或重复计费。离网模式禁止购电、缺电限速，储能遵守容量与充放电功率限制。
- 贷款采用模拟日利率 2%，预览与实际还款使用同一算法。每日收支包含维护、贷款还款及当日支付的租金，不包含设备投资、贷款入账和随机事件。
- 运行时依赖本地提供，不需要 Tailwind CDN 或 ECharts CDN。手机布局始终显示定价、设备购买与速度控制；支持键盘与减少动态效果偏好。

## 关卡

| 关卡 | 期限 | 初始资金 | 经营目标 | 首期租金 / 每周递增 |
| --- | --- | ---: | --- | ---: |
| 第一度电 | 7 天 | $1,800 | 交付 1,600 kWh，净资金 ≥ $2,300 | $350 / $0 |
| 阳光合伙人 | 14 天 | $3,200 | 2 组光伏，净资金 ≥ $2,000 | $900 / $180 |
| 快充时代 | 21 天 | $3,800 | 3 台快充，净资金 ≥ $4,500 | $1,200 / $220 |
| 离网绿洲 | 14 天 | $2,800 | 交付 2,200 kWh，净资金 ≥ $500 | $650 / $130 |
| 峰谷博弈 | 28 天 | $3,600 | 净资金 ≥ $9,000 | $900 / $200 |
| 城市旗舰 | 40 天 | $4,500 | 12 台桩、其中至少 5 台快充，净资金 ≥ $26,000 | $3,000 / $700 |

所有关卡都需避免破产，并在期限结束时满足**全部**目标。到期租金必须先支付，再判断胜利。净资金为余额减未还贷款本金，避免临近期限借款凑目标。第一关免随机事件；离网关初始 2 组光伏、1 组储能、50 kWh 存电，需要应对夜间与阴雨天供电不足。通关获得一星，各关两星/三星净资金门槛分别为 $2,600/$3,200、$3,500/$4,500、$6,500/$8,500、$3,000/$4,500、$12,500/$16,000、$35,000/$45,000；目标说明会显示门槛。

设备基础采购价及日维护费：慢充 $800/$12，快充 $2,400/$35，光伏 $1,200/$8，储能 $1,800/$18，配电 $1,000/$15；同类连续采购递增 10%，离网采购优惠 25%，事件折扣仍生效。光伏降低直接用电成本，储能需要更长回本周期；扩建时要同时预留维护和租金。自由经营启动资金 $2,800。

`npm run balance` 使用真实客流、车型、天气、事件、调度和结算规则，分别回放默认挂机与规划投资策略，每关 20 个固定随机种子（171 的整数倍）。本版挂机在第 4、5 关均为 0/20 通关；参考策略六关分别为 19、18、17、18、19、19/20。参考策略并非最优策略，结果只代表这些固定场景，不代表玩家总体通关率。阶段性扩建策略及购入设备见 `scripts/balance.cjs`。

新开的局使用调整后的资金与设备采购价；旧局保存的资金、资产和已生成采购价保留，恢复后使用当前维护、租金及目标规则。已解锁关卡与历史最佳星级保留。可重开当前关卡体验完整新平衡。

自由经营保留标准、超充、离网、鬼城、豪华、限电、通胀、雨季、高频租金九种模式，目标生存 100 天。城市分时电价为游戏参数，并非实时商业电价。

## 车辆模型

以下是用于探索调度逻辑的虚构车型参数，不对应某个品牌或具体型号。充电至 100%；当前模型使用恒定的接受功率上限，尚未模拟接近满电时的充电降功率。实际功率受车辆交流/直流上限、桩功率、站点配电及可用能源共同约束。标准快充桩额定 30 kW，因此即使车辆支持 150 kW，也只会接受不超过桩与站点允许的功率。

| 出租车 | 58 | 7 | 60 |
| SUV | 82 | 11 | 120 |
| 跑车 | 70 | 11 | 150 |
| 巡逻车 | 62 | 11 | 90 |
| 救护车 | 86 | 22 | 100 |
| 厢式车 | 76 | 7 | 50 |
| 皮卡 | 110 | 11 | 180 |

原有存档中已到站、尚无车型参数的车辆保留原来的待充电量和功率规则，驶离后新客户使用新的车型模型。曲线与存档继续兼容 v2。

## 本地运行

```bash
python3 -m http.server 4175 --directory docs
```

打开 `http://localhost:4175/`。运行游戏不需要安装 Node 依赖。

修改样式或运行检查：

```bash
npm ci
npm run build
npm test
npx playwright install chromium
npm run test:layout
npm run balance
```

`npm run build` 将 Tailwind 工具类编译到 `docs/utilities.css`，产物需一并提交。主要自定义样式在 `docs/style.css`。

## 文件结构

- `docs/index.html`：正式入口与语义化界面。
- `docs/campaign.js`：关卡、经营提示、自动存档和增强交互。
- `docs/game.js`：时间循环、设备、客流、事件、结算、站点绘制。
- `docs/vehicles.js`：车型容量、接受功率、初始电量分布与 SOC。
- `docs/station-art.js`：车辆、充电桩与站点矢量美术，独立于调度逻辑。
- `docs/energy.js`：供电调度与实际电量计费。
- `docs/finance.js`：贷款预览、还款和最终本金结清。
- `docs/vendor/`：本地 ECharts 及其许可证。
- `scripts/balance.cjs`：用真实游戏规则进行可复现的数值回放。
- `tests/`：能源守恒、离网、贷款、暂停、存档、目标和完整通关回归测试。
- `docs/index_test.html`：旧测试地址，自动跳转正式版。

## 部署
